    35→Task: Build all API routes (auth, user, paste, file, admin) with resource-based PUT/PATCH/DELETE/GET and standard envelope
    36→
    37→Work Log:
    38→- Auth routes:
    39→  - POST /api/auth/login (rate-limited, sets session cookie, returns SafeUser)
    40→  - POST /api/auth/logout (clears cookie)
    41→  - POST /api/auth/verify (sandbox: auto-verifies current session user)
    42→  - POST /api/auth/refresh (rotates cookie)
    43→  - POST /api/auth/forgot-password (creates reset token stored in SiteSetting, returns token in dev mode)
    44→  - POST /api/auth/reset-password (consumes token, sets new bcrypt hash)
    45→  - GET /api/auth/me (returns current user from session)
    46→- User routes:
    47→  - PUT /api/user (register — auto-active in sandbox, sets session cookie)
    48→  - PATCH /api/user (update own displayName / password / regenerate apiKey)
    49→  - DELETE /api/user (delete own account, requires currentPassword)
    50→  - GET /api/user (own profile, or ?list=1 admin-only listing with paste counts, or ?id=<id> specific user)
    51→  - /api/user/[id] GET (public profile) + PATCH/DELETE guarded to /api/admin/user/[id]
    52→- Paste routes:
    53→  - PUT /api/paste (create text paste — guest gating, private requires login, burn+password mutually exclusive, expiry presets)
    54→  - PATCH /api/paste (update own paste fields)
    55→  - DELETE /api/paste (soft-delete own paste)
    56→  - GET /api/paste (?id fetch single w/ access control + view counter + burn logic; ?scope=public|own|trending|language; ?q= search; ?language=; pagination)
    57→  - /api/paste/[id] GET (same single-fetch logic)
    58→  - GET /api/paste/raw?id= (plain-text response, not enveloped)
    59→  - POST /api/paste/unlock (verify password, returns 200/401)
    60→- File routes:
    61→  - PUT /api/file (multipart upload — size limit from settings, visibility/burn/password/expiry, stores via LocalStorageProvider)
    62→  - GET /api/file?id=&meta=1 (metadata) or ?id= (streams bytes, burn-on-read deletes storage)
    63→  - DELETE /api/file (soft-delete + storage delete)
    64→- Admin routes:
    65→  - GET/PATCH/DELETE /api/admin/user + /api/admin/user/[id] (ban/suspend/verify/role/delete, audit-logged)
    66→  - GET/PATCH/DELETE /api/admin/paste + /api/admin/paste/[id] (flag/force-expire/visibility/delete, audit-logged)
    67→  - GET/PATCH /api/admin/settings (full settings object, partial update)
    68→  - GET /api/admin/audit (recent admin actions)
    69→  - GET /api/admin/analytics (totals, top languages, storage usage, 14-day traffic)
    70→- Bonus: GET /api/languages (public language browse data)
    71→- Verified via curl: /api/auth/me, /api/paste PUT, /api/paste?id= GET, /api/paste?scope=public GET, /api/auth/login — all return correct envelope shape.
